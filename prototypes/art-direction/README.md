# Prototype: hướng đồ hoạ mới (ném đi, không merge)

Prototype cho ticket "Hướng đồ hoạ mới cho Hub và các Game" (#204). Mở file HTML trực tiếp trong trình duyệt; đổi phương án bằng thanh ở đáy hoặc phím ← →.

- `round1-directions.html`: 4 hướng (A Xóm chài đồ chơi, B Sơn mài tối giản, C Nền tảng trung tính, D Quán vỉa hè đất sét). Chọn **C**.
- `round2-hub.html`: 3 bố cục Hub kiểu giao diện chiến thuật cho điện thoại (1 Bảng nghiêng, 2 Băng thẻ, 3 Sơ đồ). Chọn **sảnh của 2, phòng chờ của 1, nền tối**.
